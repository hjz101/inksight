# 元数据与提审合规清单 · 墨见 InkSight

v1.0｜给提审 / 运营 / 市场｜摘自行业合规意见书与 PRD v1.6｜标 **Blocker** 者不达标即不得提交

## 0. 为什么元数据比界面更危险

界面可以改设计、可以重新画，**元数据是提审时的书面承诺**，长期留在商店页面、关键词与更新说明里，可被截图、可被调取、可被公证。

在 App Store 5.2 拒审与著作权诉讼里，"你自己怎么描述这个 App"是最省力的证据——不需要证明你抓了什么，只需要证明你声称过什么。**界面做干净了但元数据带词，一样被拒、一样被引。**

## 1. 绝对禁词（Blocker）

| 禁词 | 为什么 |
|---|---|
| 书源、书源规则、换源、源 | 自认具备并运营"针对性抓取规则"，是帮助侵权的书面自认 |
| 聚合、聚合搜索、全网 | 自认聚合他人内容，"用户感知为本 App 提供"的直接证据 |
| 免费、免费看、免费读全本、海量 | 版权语境下"免费"≈"免费提供他人作品"，自证 |
| 破解、去广告、纯净版、去水印 | 自认规避技术措施、去除权利管理信息 |
| 追更、连载、全本、最新章节 | 暗示提供连载内容服务，触发网络出版服务资质门槛 |
| 更多源、源失效、换源补章 | 同上，且出现在更新说明里删不掉 |

**推荐替换词**：本地图书、导入你的书、EPUB / TXT 阅读器、精读、排版、墨水屏质感、进度与笔记。

## 2. 逐字段检查表（Blocker，逐项签字）

| 字段 | 检查项 |
|---|---|
| App 名称 | 无禁词；不得含他人商标、平台名、作品名 |
| 副标题（≤30 字符） | 无禁词；描述工具属性，不描述内容来源 |
| 关键词（100 字符） | 无禁词；不得堆砌他人品牌词（商标风险） |
| 描述首段 | **第一句必须是"本地阅读器"定位**，不得以"海量""全网"开场 |
| 截图（全部） | 无真实站点名 / 域名 / 水印 / 他人封面；无"某书免费可读"示意；无灰色按钮＋解锁文案 |
| 预览视频 | 同上；不得出现抓取过程、加载第三方页面的画面 |
| 更新说明 | 见 §6，历史不可改 |
| 开发者名称 | 不得含"阅读""书城""小说"等易与内容提供者混淆的表述 |
| 支持 URL / 隐私政策页 | 首屏须有本地阅读器定位＋投诉入口 |

## 3. 免责声明标准文本（全公司统一版本，不得派生改写）

**禁止表述（三条都是反向自证）**

1. ~~"本 App 不存储任何内容，内容均来自第三方。"~~ → 看似免责，实为承认"我提供第三方内容"
2. ~~"所有内容均由用户提供，与本公司无关。"~~ → 暗示明知用户提供侵权内容而不作为
3. ~~"仅供学习交流，请于 24 小时内删除。"~~ → 司法实践中普遍不被认可，反而证明明知

**标准表述**

> 墨见 InkSight 是一款本地 EPUB / TXT 阅读器与排版工具。App 仅解析用户设备上的本地文件，不提供、不存储、不索引任何第三方作品内容，不设内容来源接入。

> 如你认为本 App 的任何内容侵犯你的权利，请通过 `<邮箱>` 联系我们，我们将在收到有效通知后 72 小时内处理。

**注意**：投诉承诺必须真实可执行——写进用户协议与 App 内静态页，有人值守、有台账。写而做不到，比不写更糟。

## 4. 提审备注（Review Notes）标准要点

1. 一句话定位：本地 EPUB / TXT 阅读器，内容仅来自用户设备本地文件。
2. 权限用途逐项说明（相册/文件/通知），说明"仅用于导入用户自己的文件"。
3. 提供无需账号即可完整体验的演示路径。
4. 年龄分级 17+，说明首启分龄与未成年人模式。
5. 未成年人模式说明用词：**"架构上不存在第二条出网路径"**；**不得写"完全断网""无法绕过"**——平台不提供进程级断网能力，绝对表述会被追问并损伤整体可信度。
6. 投诉与权利声明入口的位置（设置页具体路径）。

**禁忌**：不得在备注里提及审核期关闭某功能、或"审核通过后开启"（2.5.19 诱饵式营销，后果为下架＋终止开发者账号）。

## 5. 市场与外宣纪律

对外任何渠道（官网、社群、KOL 投放、软文）不得出现"聚合""全网""免费看"；不得演示抓取过程；不得以"替代付费阅读"为卖点。外宣素材与提审材料受同一套禁词约束。

## 6. 变更纪律

- 名称 / 副标题 / 关键词 / 描述 / 截图任一变更，走一次合规复核，逐条比对 §1。
- **更新说明是历史快照，删不掉。** 任一版本写过"新增书源支持""支持更多源"，即便后续删除功能，那条记录仍在商店历史与第三方抓取档案里，会被作为"曾经具备并运营该能力"的证据。
