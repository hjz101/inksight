# 禁词与文案合规检查表 · 墨见 InkSight

v1.0｜给视觉 / 前端 / 文案 / 运营 / 提审，**四方共用同一份**｜行业专家 顾纵深
触发背景：视觉侧在 ⑤ 页写「当前：xxx.txt · 2.1MB · **精校版**」，属实际违规。不知道清单的人一定会踩，靠事后纠错成本更高。

## 0. 适用范围与唯一例外（先读这一节，否则会误用）

| 范围 | 是否受本表约束 |
|---|---|
| 主链路 UI 文案（首启、书架、阅读器、⑤、空态、错误态、设置） | **严格约束** |
| App Store 元数据（名称、副标题、关键词、描述、截图、预览视频、更新说明） | **严格约束** |
| 对外物料（官网、社群、投放、软文、分享卡片文案） | **严格约束** |
| 用户协议、隐私政策、对外声明 | **严格约束** |
| 「我 → 高级 → 书源（实验）」入口**内部** | **例外**：须如实描述真实功能，但不得营销化、不得使用本表 E/F 类词 |

**为什么要有这个例外**：高级入口内如果把"书源"改叫"实验功能"，构成隐瞒功能（违反 2.5.19）。**主链路零禁词 + 实验入口内如实**，才是正确解法。切忌把本表套到实验入口里造成反向问题。

## 1. 七条判据（清单会过时，判据不会）

遇到表里没有的新词，用这七条判：

1. 它是否在描述"**我们提供内容**"？（而不是"我们处理你的文件"）
2. 它是否在描述内容的**来源数量或广度**？（多、全、遍、海量、跨站）
3. 它是否在描述内容的**完整性或更新**？（全本、完结、最新、追更、补）
4. 它是否在描述"**无代价获取**"？（免费、省钱、替代付费）
5. 它是否**指向特定第三方或权利人**？（平台名、域名、作者名、独家）
6. 它是否暗示**技术规避或去除他人标识**？（破解、去广告、去水印、净化、纯净）
7. 它是否是一个**我们无法履行的承诺**？（永久、100%、官方、授权）

**任一条为"是"，即为禁词。** 拿不准时按"是"处理——文案改一句话的成本，远低于一句自认的代价。

## 2. 分类禁词表

### A. 内容来源类（最高频，判据 1）

| 禁词 | 为什么 | 替换 |
|---|---|---|
| 书源、源、换源、多源、源站、订阅源 | 自认具备并运营"针对性抓取规则"，是帮助侵权的书面自认 | 文件、本地文件、版本、副本 |
| 书源规则、规则文件、书源导入、粘贴即读 | 同上，且指向规则分发 | （主链路不出现；实验入口内如实） |
| 接口、线路、通道、镜像站、采集 | 换了皮的"源" | 删除 |

### B. 聚合与规模类（判据 2）

| 禁词 | 为什么 | 替换 |
|---|---|---|
| 聚合、聚合搜索、跨站、一站式 | 自认聚合他人内容，正中"用户感知为本 App 提供" | 本地书架、你的书 |
| 全网、全库、海量、百万书库、搜遍全网 | 规模暗示，等于宣称内容体量 | 删除，或改"你导入的书" |

### C. 免费与无代价类（判据 4）

| 禁词 | 为什么 | 替换 |
|---|---|---|
| 免费、免费看、免费读全本、永久免费、0 元 | 版权语境下"免费"≈"免费提供他人作品"，是自证 | **直接不提价格**，不要找替代词 |
| 省钱、替代付费、正版平替、看小说不花钱 | 直接指向"替代正版市场"，是实质性替代的自认 | 删除 |

### D. 完整性与更新类（判据 3）

| 禁词 | 为什么 | 替换 |
|---|---|---|
| 全本、全集、完本、完结、无删减、未删节 | 承诺内容完整性，且触发网络出版服务资质联想 | 版本对比、位置对齐 |
| 最新章节、追更、连载、更新提醒、补章、补全 | 自认提供连载内容服务 | （主链路不出现） |
| 精校版、精校、校对版、修订全本 | **本次事故词**。既是完整性承诺，又是"我们保证质量"的无法履行承诺 | 用户可编辑的纯文本版本标签，默认「未命名版本」，**我方不贴任何值** |

### E. 技术规避类（判据 6）

| 禁词 | 为什么 | 替换 |
|---|---|---|
| 去广告、拦截广告、屏蔽广告、去水印 | 自认去除他人商业标识；该类行为在诉讼中直接证明主观故意 | 排版整理 |
| 净化、净化规则、纯净版、无广告阅读 | "净化"本身就隐含"清除他人添加的内容" | **排版清理**、清理空行 |
| 破解、解锁、绕过、去限制、免登录 | 自认规避技术措施 | 删除 |

### F. 第三方与权利人指向（判据 5，最致命）

| 禁词 | 为什么 |
|---|---|
| 任何具体平台名、站点名、域名、App 名 | 直接指向权利人，是最容易被单点起诉的一类 |
| 任何作者名、"某平台独家""独家作品可读" | 同上，且构成虚假宣传风险 |
| 关键词字段堆砌他人品牌词 | 商标侵权独立风险 |

替换：**一律删除，不给替代词。**

### G. 承诺与资质类（判据 7）

| 禁词 | 为什么 | 替换 |
|---|---|---|
| 永久、终身、绝不、100%、全网最全 | 无法履行的承诺，构成虚假宣传 | 删除 |
| 官方、正版、授权、签约（无授权文件时） | 无授权文件即构成虚假宣传，且在版权争议中成为加重情节 | 删除；**确无授权时一个字都不能写** |

## 3. 未成年人模式专项禁词

### 3.1 绝对禁（未成年人模式内不得出现）

书源、搜索、限制、解锁、退出、切换模式、监护验证后可切换、任何解锁路径提示。

### 3.2 有条件禁（v1.0 修正：原表把「联网」「导入」一刀切禁掉，范围过宽，已收窄）

| 词 | 禁的范围 | 允许的范围 | 理由 |
|---|---|---|---|
| **联网** | "联网找书""联网获取内容""联网搜索" | **"设备联网后""网络可用时"** | 前者描述我方提供内容接入；后者仅描述用户设备的网络状态，是两件事 |
| **导入** | 未成年人模式文案内 | **主链路可用**（"导入你的书"是 B 版核心定位） | 未成年人模式内确无导入功能，出现即造成困惑；主链路为真实功能，如实用词 |

**判断口径**：禁的是"描述我们提供某种能力"的表述，"描述用户设备状态"不在禁列。

### 3.3 时间信息边界

- **禁**："将于 X 点恢复""还有 X 小时可用"——时间点/倒计时，形成"等待—到点—立刻使用"的循环，与防沉迷目标相反。
- **允许且必要**："完善年龄信息后返回即可生效"——**动作路径**，不是时间点。

这一条同时满足两个要求：必须提前告诉用户怎么做（降低"当成 bug"的投诉），且不描述未来可用的时间点。

### 3.4 表达姿态

**正面列举优于负面解释。** 写"你能用什么"，不写"你被禁止了什么"。负面解释天然是剥夺叙事，且会承认我们本来有该能力。

## 4. 元数据专项（5.2 拒审最高频触发表）

名称 / 副标题（≤30 字符）/ 关键词（100 字符）/ 描述首段 / 全部截图 / 预览视频 / 更新说明 / 开发者名称 —— 逐项比对 §2。

- **描述第一句必须是"本地阅读器"定位**，不得以"海量""全网"开场。
- **截图不得出现**真实站点名、域名、水印、他人封面；不得出现"某书免费可读"示意；不得出现灰按钮＋解锁文案。
- **更新说明是删不掉的历史快照**。哪一版写过"新增书源支持"，即便后续删了功能，那条记录仍在商店历史与第三方抓档里。

## 5. 三方分工（避免"没人负责审"）

| 角色 | 职责 |
|---|---|
| 视觉 / 前端 | 写文案时先过 §1 七条判据；交付稿自带一份"文案自查"清单 |
| 文案 / 运营 | 元数据与对外物料全部走 §2 全表比对，逐项签字 |
| 提审 | 提交前对照 §4 逐字段核对，并核对提审备注与对外声明口径一致 |
| 变更 | 任一文案/命名变更走一次复核；**枚举名与用户可见名称定稿后改名也要走复核**（旧名会留在 git log、设计稿、截图里） |

## 6. 事故复盘：「精校版」

- **发生位置**：⑤ 页版本标签。
- **性质**：既是完整性承诺（D 类），又是无法履行的质量承诺（G 类）。
- **根因**：视觉侧在提产品建议时并不知道该词属禁词——**不知道清单的人一定会踩**。
- **结构性修复（比禁用词清单更稳）**：版本标签做成**用户可编辑的纯文本**，默认「未命名版本」，**我方不给它贴任何值**。这样"精校版"这类词只能来自用户自己，不来自我方表述——**把词源切掉，比逐个禁词可靠**。
- **可复用结论**：凡是"我方代替用户对内容做评价"的字段，都可能成为自认。此类字段应默认做成用户自填，而非我方预设枚举。
