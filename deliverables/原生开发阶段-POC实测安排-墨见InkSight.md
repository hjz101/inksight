## 0. 总则

1. **性质与依据**：依 **D-25**，五个 POC 实测移入原生开发阶段、本期不作验收项；本文件是 **D-16**（状态「已移期」）所指"随原生开发阶段一并交付"的实测安排，也是排期与判据的**唯一载体**。
2. **编号说明**：本文件 POC-1～POC-5 编号以收口轮定义为准（POC-1 = T1 首帧、POC-2 = 玻璃、POC-3 = CoreText、POC-4 = 连读功耗、POC-5 = 仿真 120Hz）。**架构冻结版（v1.0 §八）的 POC 编号作废**——那套编号里"POC-1 = 阅读画布"与本文件 POC-3 / POC-5 内容重叠、编号不同，引用时一律以本文件编号为准。DESIGN §9.3 的 POC-1 / POC-2 与本文件同义，不冲突。
3. **真机与模拟器的分界**：模拟器**只承担 POC-3 的功能正确性子项**（分章正确性、分页锚点正确性、标点判据的初筛）。帧率、温控、功耗、玻璃观感一律**真机**——D-16 记录的主理人倾向"模拟器先做仿真翻页 120Hz"在本文件中**不成立**：模拟器没有 ProMotion、没有真实 GPU 热轨迹，测出来的 118fps 不是证据（DESIGN §2.8 对玻璃已有同款禁令）。
4. **真机清单**：≥1 台 ProMotion 设备（iPhone 13 Pro 起，120Hz）＋ 1 台非 ProMotion 设备（60Hz 对照，验证 59fps 下限）；系统 iOS 26.x；每台设备型号与系统版本随数据留存。
5. **数据留存（硬要求，无原始数据的数不算数）**：每项 POC 留存 ① `Instruments` trace 原始文件 ② 参数快照（字号 / 边距 / 主题 / 字体 / 样本文件 MD5）③ 设备型号与系统版本 ④ 测试样本本体（同一章、同一页范围）。
6. **升级纪律**：同一判据连续两次重测不收敛 → 升级 team-lead，**不得自行放宽阈值**（阈值均来自 Blocker 级 NFR，放宽等于改判 D-01）。
7. **测试样本先行**：20MB 中文 txt（内含一段 8–12KB 无章节标记的整块文本，用于验证虚拟分节）、标点密集样本（连续引号 / 逗号 / 破折号）、图文混排章节，三项样本在 POC-3 开工前制备完毕并登记 MD5。

## 3. POC-3　CoreText 分章、标点与首屏渲染（20MB ＋ 标点密集样本）

| 项 | 内容 |
|---|---|
| **① 被测对象** | **(a) 自绘断行**：`CTTypesetterCreateLine(typesetter, 我方 range)`（禁则表＋逐字 advance 累加决定断点，显式关 `palt`/`halt` 兜底——技术约束清单 FR-031）。**(b) 标点判据**：`CTLineGetTypographicBounds` 与自绘累加 advance 之差（**判据原文见技术约束清单 FR-031：>0.5pt 判不可行**）。**(c) 分章扫描**：memchr 找 `\n` ＋ 行首 64 字节内匹配章节标记，只产 `(offset, byteLength)` 不解析正文（NFR-08）。**(d) 首屏分页 ≤8ms（不含网络）与全章分页 15–30ms**。**(e) 20MB txt 首开**：分章 40–80ms、首章分页、峰值内存 ≤400MB（NFR-03/NFR-08）。**(f) 冷启动双指标**：首帧 ≤800ms、首屏可交互 ≤1.2s（NFR-01，不合并）。**(g) 字体静默降级校验**：`CTFontCopyFamilyName` 与请求族名一致（字体 fallback 是"无声违规"类，E-02） |
| **② 量具** | Instruments（Time Profiler ＋ Allocations ＋ VM Tracker）；自建 `os_signpost` 三点：`chapter.scan` / `page.firstScreen` / `page.fullChapter`；内存峰值用 VM Tracker 的 dirty + compressed 口径 |
| **③ 判据（阈值＋出口条件）** | **(b) 标点**：差 ≤0.5pt → 通过；>0.5pt → 重测一次；仍 >0.5pt → **判不可行**，触发两条回退路径（见 ⑦）。**(c) 分章**：20MB ≤100ms（预算 40–80ms ＋ 余量）→ 通过；>100ms → 优化扫描（跳过 BOM/编码探测重跑）；>200ms → 不通过。**(d) 首屏分页** ≤8ms → 通过；8–15ms → 重测一次并缩首屏为半屏复测；>15ms → 不通过。**(e) 内存**峰值 ≤400MB → 通过；400–450MB → 优化位图策略后重测；>450MB → 不通过。**(f) 冷启动**：双指标各测 20 次取 P95，均在阈内 → 通过；首帧 >800ms → 不通过（回退：延迟非首屏资源装载）。**(g) 字体校验**：模拟字体替换场景下校验生效（纳入 `TypographySignature`）→ 通过 |
| **④ 依赖与前置** | 字体白名单已打包（苹方按名称引用 ＋ 思源宋随包 OFL，含 LICENSES 文件）；禁则表 v1；`[Paragraph]` 结构化数据可产（ContentExtractor 可用）；三份测试样本已制备并登记 MD5 |
| **⑤ 执行顺序** | **最先启动（与 POC-2 并行）**——它是 POC-1（z2 需真实排版）与 POC-5（分页锚点）的前置。功能正确性子项可先在模拟器跑 |
| **⑥ 估时** | **3 人日**（含 20MB 样本制备、标点样本、真机） |
| **⑦ 责任方与回退** | 架构侧主导（排版引擎 2.0 人日计入基线，本 POC 是其验收）。**失败回退**：标点判不可行 → ①启用逐字形定位绘制（+1.5 人日，需 team-lead 批）或 ②降级为「同字体零位移」（前置条件不成立时的既定降级，需 PM 改 FR-031 承诺口径）。分章超时 → 空行密度虚拟分节 ＋ 懒分章（打开后后台补目录）。冷启动不达标 → 增量迁移延后、封面懒加载 |

## 4. POC-4　连续阅读 30 分钟（功耗与温控）

| 项 | 内容 |
|---|---|
| **① 被测对象** | 真机连读 30 分钟：外壳温升、电量消耗、是否触发系统降亮度。**前置逐条验证**（NFR-06 的前提——**指标是架构换来的，不是调优出来的**）：阅读页 0 玻璃、静止 3s 停 `CADisplayLink`、`preferredFrameRateRange` 仅动画期 118–120、无逐帧自绘玻璃、心跳不逐 tick 写库（`ReadingClock` 60s 或 10 页合并落盘） |
| **② 量具** | **外部测温**：接触式温度计或红外热像仪，固定测外壳同一点（摄像头下方背面），**25℃ 恒温环境**，每 5 分钟记录；电量：IORegistry `BatteryCurrentCapacity` 逐分钟采样 ＋ 系统电量百分比双录；亮度：`UIScreen.brightness` 与系统状态截图双录 |
| **③ 判据（阈值＋出口条件）** | **通过**：30 分钟温升 ≤4℃（25℃ 室温）且掉电 ≤5%（**D-01 红线**）且未触发降亮度。**重测**：温升 4–6℃ 或掉电 5–8% → 允许两项微调（心跳合并粒度加大 / 静止停帧从 3s 收到 1s）后复测一次。**不通过**：温升 >6℃ → 回退方案见 ⑦，并升级 team-lead（回退触碰 NFR-02 的 118fps，需要裁决） |
| **④ 依赖与前置** | POC-3（真实可读内容）、POC-5 或任意翻页模式（要有真实翻页动作）、25℃ 可控环境；被测机满电、关闭后台 App 刷新、飞行模式 + 本地书（排除网络变量） |
| **⑤ 执行顺序** | **最后执行**——需要 POC-3 / POC-5 的成果，且要在"玻璃策略定稿（POC-2）"之后测，否则测的是将被推翻的配置。**不阻塞任何产品决策** |
| **⑥ 估时** | **1.5 人日**（3 轮 × 30 分钟 ＋ 环境准备与测温记录） |
| **⑦ 责任方与回退** | 架构侧出方案，QA 执行记录。**失败回退**：①静止停帧 3s → 1s；②动画期帧率上限 118 → 60（ProMotion 省电模式）；③复查隐性 GPU 工作（`Degradation` 申报清单逐条过）。**注意**：②会触碰 NFR-02，必须 team-lead 裁，不得自行改 |

## 5. POC-5　仿真翻页 120Hz（Blocker，最高优先）

| 项 | 内容 |
|---|---|
| **① 被测对象** | `CAMetalLayer` ＋ 顶点着色器柱面变形（网格 24×16，逐帧只更新 uniform）；页位图纹理（降采样 2x，`.private` storage，不逐帧上传）；`CADisplayLink` `preferredFrameRateRange` 118–120；前后各 2 页位图预取（仅仿真翻页时物化，NFR-03）；**顺带量跳章首屏分页 ≤8ms**（与 Metal 管线同场，POC-3 的 d 项在此复测端到端体感） |
| **② 量具** | Instruments（Core Animation 帧时间 ＋ Metal GPU）；自建帧记录器：每帧 `duration` 与 `targetTimestamp` 差值逐帧落盘；掉帧率 ＝ |duration| > 8.33ms 的帧占比；**连续 60s 快速连续翻页**（含来回翻，暴露相邻章预取是否命中） |
| **③ 判据（阈值＋出口条件）** | **通过**：ProMotion 真机 60s 连续翻页帧率 ≥118fps、掉帧率 <1%、单帧 P95 ≤16.7ms（NFR-02 全条）→ 仿真翻页定稿。**重测**：110–118fps → 关闭全部玻璃浮层复测一次（验证是否 backdrop 争 GPU）；仍不达标 → 不通过。**不通过**：<110fps，或掉帧率 ≥1% → 回退"平移＋阴影"伪翻页（同一位图管线、仅变换矩阵不同，成本 <1ms），**该回退需 PM 确认观感降级可接受**。跳章分页 >8ms → 不通过（回退：首屏缩为半屏） |
| **④ 依赖与前置** | POC-3 的分页锚点（可先用手排锚点 mock 启动）；POC-2 结论验证"翻页期玻璃收起/纯色"确实生效（NFR-02 前提）；非 ProMotion 设备对照（59fps 下限） |
| **⑤ 执行顺序** | **Blocker，与 POC-3 并行启动**（mock 锚点先行）；正式判据在 POC-3 分页可用后出。**它是五项里唯一"不通过即推翻架构"的项**（v1.0 起的定性不变） |
| **⑥ 估时** | **3 人日**（Metal 管线 ＋ 帧记录器 ＋ 真机 60s 采样 × 3 轮） |
| **⑦ 责任方与回退** | 架构侧主导。**失败回退**：伪翻页（功能保留、观感降级，需 PM 确认）；若连伪翻页都掉帧 → 说明问题不在翻页而在管线，转架构侧重估整个渲染层（此时回到 v1.0 就写明的"架构需重估"分支） |
