## C. 禁词 +3 与"评价字段"通用规则（PM 新增，本节影响多个页面）

**新增禁词**：
1. **「净化」本身即禁词**（不只是"去广告"）——隐含"清除他人添加的内容"。UI 统一改「**排版清理**」。我的稿 0 处（唯一出现是自查声明本身）。
2. **「更新提醒」**在主链路是禁词（暗示提供连载更新服务）。我的稿 0 处，书架"有更新"角标在本版不存在。
3. **「授权」二字在无授权文件时一个都不能写**（含"正版授权""已获授权"）——虚假宣传 + 版权争议加重情节，**比"精校版"重**。我的稿 0 处。

**通用规则（比逐词禁更管用，PM 原话，已置于判据清单首位之一）**：
> **凡"我方代替用户对内容做评价"的字段，都可能成为自认。此类字段应默认做成用户自填，而非我方预设枚举。**

**按此复查我现有设计的改造清单**：

| 位置 | 原设计 | 改为 |
|---|---|---|
| ⑨ 书籍详情 | 曾设"阅读难度 / 质量描述 / 标签"等预设枚举 | **只显示客观可核字段**：文件名、格式、大小、章节数、导入时间。**难度/评分/质量描述一律不做**；标签改为**用户自建自由文本**，我方不预置任何值 |
| ⑨ 书籍详情 · 封面 | 曾标"封面来源" | 改为「封面来自你的文件」（陈述来源，不评价），或用户自填 |
| ⑤ 换一份文件 | 曾写"精校版" | 已改「未命名版本」，版本标签用户可编辑、我方不预置 |
| ③ 书架角标 | 曾考虑"更新 N 章" | **不做**（"更新"语义在主链路禁词） |
| ⑦ 墨量 | 统计只报自己的行为数据 | 不加"你超过了 X% 用户"类比较性评价（代用户评价 + 促使用量） |

## D. 反向禁词（架构提醒，新增一类自查）

**「全文索引 / 全文检索」本身是中性技术词，但单独出现时读起来像"我们持有全文"——恰好是合规最敏感的方向。**
规范要求：引用时**必须带限定**，不得单独出现 → 统一写「**仅对本地导入文件建立索引**；在线内容不落盘、不建索引」。我的稿 0 处，但把它写进自查清单，防止后续新增时裸用。
**这类"反向禁词"（不宣称完整、而是暗示持有）比正向禁词更难被词表抓到，因为它本身是中性的。**
