### A.1 可关性与实现手段（回答许清楚的问题）

**我稿里原来画成系统 sheet morph 的有两处：④ 阅读设置浮层、⑤ 换源面板。已在 v1.2 全部改为自绘浮层**，所以现在**没有任何一处依赖系统 push / sheet morph**。13 条全 A 档「可完全关，零残余」。
唯一还要你确认的：自绘 sheet 必须补四条（44pt 关闭按钮、`accessibilityAction(.escape)`、36×4pt 把手、scrim 点击关闭），四条已列为验收项。若你更想保留系统 sheet 的原生手感，只能牺牲这两处的可关性——需要你在 PRD 里定。

### A.2 我拦下的两条 EGG 越界风险（已按 PM 裁决收口）

- **EGG4 在阅读页**：与「阅读页只保留克制动效」的边界靠四条约束守住——① 无循环动画；② 只跟手，松手即静态；③ 折角区不叠玻璃、不加阴影、不发光；④ 热区限定右下 44×44pt，不与翻页手势区重叠（翻页手势有效区排除该角）。验收按这四条逐项过。
- **EGG5 唤出的是 ⑤ 换源面板**（Thick 单浮层），不是书摘卡。阅读态仍 0 处玻璃，浮层态 1 处，不变式成立。**这也顺带解掉了我上报的 T2 宿主断点**：T2 舞台回到 ⑤，常规入口走 chrome 菜单「换源」，摇一摇是快捷路径。

## E. 玻璃「收起」规则（P0 验收项，与架构约束合并成一条）

许清楚要求「翻页或滚动时浮层玻璃收起为半透明纯色」，高见远要求「转场期间不许驱动玻璃重算」——两者是同一件事，合并为下表：

| 状态 | 玻璃表现 |
|---|---|
| 静止 | 全参数：backdrop-filter + tint + 四层折射 |
| 翻页 / 滚动中 | **`backdrop-filter: none` + `rgba(surface, .92)` 纯色 + 1pt 描边**，opacity 保持，不形变、不改 tint |
| 转场 380ms 内 | 仅 opacity 变化，材质冻结（不重采样 backdrop） |
| 手势跟手（UIT1/EGG2/EGG4） | 同上，纯色；手势结束后 120ms 淡回全参数 |

这样既满足「收起为半透明纯色」的 P0 验收，也不触发 GPU 二次全屏采样。**正文区在任何状态下都是零材质、零阴影，这条不因上表松动。**
