混排规则：中西文之间插入 1/4 em 空隙（英文/数字用 SF Pro，中文用苹方）；中文标点全角、行首禁则（`line-break: strict`）；正文段间距 0.75em，首行缩进 2em 默认关。

### 1.3 间距与栅格

4/8 基准：2、4、8、12、16、20、24、32、40、48、64（sp-1…sp-11）。
页面左右边距 20（阅读页 24，可在 0–40 调）；卡片内边距 16；卡片间距 12；分组间距 32；列表行高 56；顶栏 44；TabBar 49 + 安全区；主按钮高 50。
网格：书城 2 列，列间距 12，封面 3:4；书架网格 3 列，间距 16。

### 1.4 圆角

- **容器圆角**（固定半径，几何圆）：r-8 图标底、r-12 输入/标签、r-16 缩略图/按钮。
- **连续曲率圆角**（squircle，用于卡片/浮层/玻璃）：c20 卡片、c26 大卡片与浮层、c32 模态与 sheet。iOS 侧 `RoundedRectangle(cornerRadius:style:.continuous)`；CSS 优先 `corner-shape: squircle`，不支持时降级 `border-radius: 值 × 1.12`。
- 规则：同屏不混用两种曲率；**玻璃一律连续曲率**（折射需要平滑轮廓，几何圆角在 1px 描边处会出现硬转折）。

### 1.5 阴影与层级

| 级 | 参数 | 玻璃 |
|---|---|---|
| z0 | none | 平铺层/正文 |
| z1 | `0 1px 2px rgba(0,0,0,.06), 0 1px 1px rgba(0,0,0,.04)` | 否 |
| z2 | `0 4px 12px rgba(0,0,0,.08), 0 1px 2px rgba(0,0,0,.05)` | 薄玻璃 |
| z3 | `0 12px 32px rgba(0,0,0,.12), 0 2px 6px rgba(0,0,0,.06)` | 标准玻璃 |
| z4 | `0 28px 64px rgba(0,0,0,.18), 0 4px 12px rgba(0,0,0,.08)` | 厚玻璃/模态 |

夜间阴影不加深（深底上无效）：改用 `1px solid rgba(255,255,255,.06)` + `inset 0 0 0 1px rgba(255,255,255,.04)`，阴影透明度 ×0.6。

## 二、Liquid Glass 材质规范

### 2.1 三档配方

| 参数 | Thin（TabBar/胶囊/小控件） | Regular（卡片/浮层/分段） | Thick（模态/大面板） |
|---|---|---|---|
| backdrop-filter | `blur(12px) saturate(140%) brightness(1.04)` | `blur(24px) saturate(160%) brightness(1.06)` | `blur(40px) saturate(180%) brightness(1.08)` |
| 底色渐变 | `linear-gradient(180deg, rgba(255,255,255,.14), rgba(255,255,255,.06))` | `…rgba(255,255,255,.10) → .04` | `…rgba(255,255,255,.08) → .02` |
| 主题色偏叠加 | `var(--glass-tint)` 6% | 12% | 18% |
| 边缘高光（宽/向） | `inset 0 .5px 0 rgba(255,255,255,.55)`，1px，180deg 顶亮 | `inset 0 1px 0 rgba(255,255,255,.62)`，1px | `inset 0 1px 0 rgba(255,255,255,.70)`，1.5px |
| 描边 | `1px rgba(255,255,255,.22)` | `1px rgba(255,255,255,.28)` | `1px rgba(255,255,255,.34)` |
| 内阴影 | `inset 0 -1px 2px rgba(0,0,0,.06)` | `inset 0 -1px 3px rgba(0,0,0,.08)` | `inset 0 -2px 6px rgba(0,0,0,.10)` |
| 外投影 | z2 | z3 | z4 |
| 圆角 | c20 | c26 | c32 |
| 典型 | TabBar 项、搜索胶囊、Toast | 继续阅读卡、设置 sheet 头部、分段控件 | 换源面板、主题预览、分享卡 |

### 2.2 折射与色散（4 层叠加，玻璃的观感核心）

| 层 | 实现 | 参数 |
|---|---|---|
| L1 高光环 | `::before` | `conic-gradient(from 200deg, transparent 0 42%, rgba(255,255,255,.75) 56%, transparent 70%)`，用 `mask: linear-gradient(#000,#000) content-box, linear-gradient(#000,#000); mask-composite: exclude; padding:1.5px` 做成 1.5px 亮环，左上与顶部最亮 |
| L2 体色折射 | `::after` | `radial-gradient(120% 80% at 18% -10%, var(--glass-refract) 0%, transparent 55%)` 叠 `radial-gradient(90% 70% at 92% 112%, rgba(0,0,0,.10), transparent 60%)`，不透明度 .9 |
| L3 色散双环 | 两个绝对定位 1px 描边环 | 暖环 `rgba(255,150,90,.20)` 偏移 `translate(.75px,.75px)`；冷环 `rgba(90,150,255,.20)` 偏移 `translate(-.75px,-.75px)`；`mix-blend-mode: plus-lighter`，总不透明度 .35 |
| L4 磨砂噪点 | SVG `feTurbulence baseFrequency=.9` 2px 平铺 | 不透明度 .03（深色 .05），`mix-blend-mode: overlay`，用于消除大面积玻璃的色阶断层 |

前置条件：玻璃背后必须有可折射的内容（封面/色块/图片）。纯色底上**不启用玻璃**，改「纯色 + 1px 描边」，否则只剩磨砂没有折射。降级：`@supports not (backdrop-filter: blur(1px))` → `rgba(255,255,255,.94)` / 夜 `rgba(26,26,26,.96)` + 描边。

### 2.3 浅色/深色差异与可读性

| 项 | Light | Night |
|---|---|---|
| tint 基色 | `rgba(255,255,255,.10)` | `rgba(22,24,28,.44)`（变暗而非提亮） |
| brightness | 1.04–1.08 | .92–.96 |
| 边缘高光 | .55–.70 | .18–.26 |
| 分层手段 | 外投影 z2–z4 | 描边 + 内发光，禁投影 |

可读性：玻璃上文字对比度 ≥4.5:1（<17px）、≥3:1（≥17px 且 600 字重）；因玻璃下方内容不可控，文字层必须带保障——优先 `text-shadow: 0 1px 2px rgba(0,0,0,.30)`，不达标时把 tint 提到 .20，仍不达标则改纯色底。**正文阅读区永不用玻璃、不叠 scrim、不加阴影**。

### 2.4 与 iOS 26 原生映射（建议映射，需真机校准）

## 四、动效语言

缓动：`--e-enter: cubic-bezier(.16,1,.30,1)`（进入/展开）、`--e-standard: cubic-bezier(.32,.72,0,1)`（位移/颜色）、`--e-exit: cubic-bezier(.40,0,1,1)`（退出）、`--e-soft-spring: cubic-bezier(.34,1.32,.64,1)`（仅书架/成就，可关）、`--e-linear`（进度）。
时长：instant 0 / fast 120 / base 220 / slow 380 / xslow 560 / 呼吸 6000。错峰 stagger 40ms，最多 3 批。
编排：容器先动（0ms）→ 主内容（60ms）→ 文字图标（120ms）→ 玻璃高光最后（180ms，「先形后光」）。退出反向：玻璃先散，内容后走。

| ID | 转场 | 描述 |
|---|---|---|
| T1 | 书架卡片→阅读器 | 380ms e-enter：封面 matchedGeometry 由卡片位放大至全屏（0.62→1），卡片阴影 z2→z0 220ms，正文 opacity 0→1 delay 140ms/200ms，返回按钮玻璃 delay 260ms 淡入（全页仅这 1 处玻璃） |
| T2 | 换源「换书脊」 | 260ms：书脊竖排文字 blur(6px)→0 + translateY(10px)→0；新源 accent 沿书脊 `linear-gradient` 位移扫过 240ms；**卡片尺寸不变**（防跳动） |
| T3 | 主题切换色带 | 560ms：从点击点 `clip-path: circle(0% → 150%)` e-standard，新色层在下、旧层 opacity→0 delay 200ms；颜色 OKLab 插值（避免灰带）；封面不变色 |
| T4 | 退出阅读→书架 | 300ms e-exit：正文 opacity→0（120ms），页面 scale 1→0.86 过渡到目标卡片 rect，书架卡片阴影 z0→z2 delay 180ms；手势取消阈值 32% 或速度 >600px/s |
| T5 | 进入沉浸模式 | 220ms e-standard：顶栏 translateY(-100%)、底栏 +100% 同时，上方 mask 淡出 120ms；**正文字号与行位置零位移**（防回跳） |
| T6 | 成就解锁 | 380ms e-soft-spring（仅墨量页）：成就卡 scale .96→1，L1 高光沿边缘走一圈 600ms linear；无粒子、无音效；同屏只播 1 次，冷启不重播 |

减弱动态效果开启时：时长 ×0，位移改为 opacity 交叉淡入。
