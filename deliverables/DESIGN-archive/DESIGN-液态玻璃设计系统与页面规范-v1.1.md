4/8 基准：2、4、8、12、16、20、24、32、40、48、64。页面左右边距 20（阅读页 20，可调 0–40）；卡片内边距 16；卡片间距 12；分组间距 32；列表行高 56；顶栏 44；TabBar 49 + 安全区；主按钮 50。书城 2 列 gap 12 封面 3:4；书架网格 3 列 gap 16。

### 1.4 圆角

容器圆角（几何圆）：r-8 图标底、r-12 输入/标签、r-16 缩略图。
连续曲率圆角（squircle）：c20 卡片、c26 大卡与浮层、c32 模态/sheet。iOS `style: .continuous`；CSS 优先 `corner-shape: squircle`，不支持降级 `border-radius × 1.12`。
玻璃一律连续曲率（1pt 高光描边遇几何圆角会硬转折）。**蜜桃汽水主题整体 +4**（c24/c30/c36），这是该主题「圆角更大」的落地值。

## 二、Liquid Glass 材质规范

### 2.1 三档配方

| 参数 | Thin（TabBar/胶囊/小控件） | Regular（卡片/浮层/分段） | Thick（模态/大面板） |
|---|---|---|---|
| backdrop-filter | `blur(12pt) saturate(140%) brightness(1.05)` | `blur(24pt) saturate(160%) brightness(1.06)` | `blur(40pt) saturate(180%) brightness(1.08)` |
| 底色渐变 | `linear-gradient(180deg, rgba(255,255,255,.14), rgba(255,255,255,.06))` | `…rgba(255,255,255,.10) → .04` | `…rgba(255,255,255,.08) → .02` |
| 主题 tint | `var(--glass-tint)` ×0.5 | ×1.0（雪纸 #FFF@28% → 28%） | ×1.4（上限 50%） |
| 边缘高光 | `inset 0 .5pt 0 rgba(255,255,255,.55)`，1pt，180deg 顶亮 | `inset 0 1pt 0 rgba(255,255,255,.62)` | `inset 0 1pt 0 rgba(255,255,255,.70)`，1.5pt |
| 描边 | `1pt rgba(255,255,255,.22)` | `1pt rgba(255,255,255,.28)` | `1pt rgba(255,255,255,.34)` |
| 内阴影 | `inset 0 -1pt 2pt rgba(0,0,0,.06)` | `inset 0 -1pt 3pt rgba(0,0,0,.08)` | `inset 0 -2pt 6pt rgba(0,0,0,.10)` |
| 外投影 | z2 | z3 | z4 |
| 圆角 | c20 | c26 | c32 |

### 2.2 折射与色散（4 层叠加 = 观感核心，非磨砂）

| 层 | 实现 | 参数 |
|---|---|---|
| L1 高光环 | `::before` | `conic-gradient(from 200deg, transparent 0 42%, rgba(255,255,255,.75) 56%, transparent 70%)`，`mask-composite: exclude` + `padding:1.5pt` 得 1.5pt 亮环，左上与顶部最亮 |
| L2 体色折射 | `::after` | `radial-gradient(120% 80% at 18% -10%, var(--glass-refract), transparent 55%)` 叠 `radial-gradient(90% 70% at 92% 112%, rgba(0,0,0,.10), transparent 60%)`；opacity = `min(.95, .40 + var(--refract))` |
| L3 色散双环 | 两个 1pt 描边环 | 暖 `rgba(255,150,90,.20)` `translate(.75pt,.75pt)`；冷 `rgba(90,150,255,.20)` `translate(-.75pt,-.75pt)`；`mix-blend-mode: plus-lighter`；总不透明度 = `var(--refract)`（主题表给定值） |
| L4 磨砂噪点 | SVG `feTurbulence baseFrequency=.9` 2pt 平铺 | opacity = `.03 + max(0, var(--refract) - .2) × .06`，`mix-blend-mode: overlay`，消除大面积色阶断层 |

前置条件：玻璃背后必须有可折射内容。纯色底上**不启用玻璃**，改「纯色 + 1pt 描边」。降级 `@supports not (backdrop-filter: blur(1pt))` → 浅 `rgba(255,255,255,.94)` / 夜 `rgba(28,28,30,.96)` + 描边。

### 2.3 浅/深差异与可读性

| 项 | Light | Night |
|---|---|---|
| tint | 主题色 @20–30% | **#1C1C1E @45%**（变暗不提亮） |
| brightness | 1.05–1.08 | .92–.96 |
| 边缘高光 | .55–.70 | .16–.22 |
| 色散 `--refract` | 0.25–0.45 | **0.20**（暗底高反光刺眼） |
| 分层手段 | 外投影 z2–z4 | 描边 + 内发光，禁投影 |

可读性：玻璃上文字 ≥4.5:1（<17pt）/ ≥3:1（≥17pt 且 600）；因底下内容不可控，文字层必带 `text-shadow: 0 1pt 2pt rgba(0,0,0,.30)`，不达标把 tint 提至 ×1.2，仍不达标改纯色底。**正文阅读区永不用玻璃、不叠 scrim、不加阴影、不加装饰字。**

### 2.4 玻璃预算（硬约束，写进图层规范）

一屏最多 **1–2 处**玻璃浮层；正文区零玻璃。玻璃仅允许出现在 4 类容器：阅读设置浮层、换源面板、主题商店预览卡、成就/墨量卡片。阅读设置浮层与换源浮层必须给**单浮层版本**（同屏不叠两个玻璃容器）；展开菜单时顶栏+底栏合并为 **1 个** Thin 视觉组，不各算一处。

### 2.5 原生映射（建议映射，需真机校准）

Thin → `.glassEffect(.clear.tint(color).interactive())`；Regular → `.glassEffect(.regular.tint(color))` + `GlassEffectContainer(spacing: 20)`；Thick → `.glassEffect(.regular.tint(color).interactive())` + `GlassEffectContainer(spacing: 32)` + `.glassEffectID`。

## 四、动效语言

缓动与时长（**以 PM 交底为准，不自行发明**）：`--e-open: cubic-bezier(.2,.9,.15,1)`；`--e-band: cubic-bezier(.4,0,.2,1)`；`--e-out`=ease-out；`--e-expo: cubic-bezier(.19,1,.22,1)`（指数衰减近似）；spring 用 damping 参数而非贝塞尔。
错峰 25pt；通用时长阶梯 fast 120 / base 220 / slow 380 / xslow 600。

### 4.1 动效注册表（FR-030 要求全部登记，未登记则构建失败）

| ID | 名称 | 起点帧 → 终点帧 | 图层与 z 序 | 时长 | 缓动 | 可中断 |

| T2 | 换书脊 | 旧源书脊 → 新源书脊（同 rect） | 脊底 z0｜竖排文字 z1｜源色渐变扫层 z2 | 260 | ease-out，文字 blur 0→3pt→0 + translateY 0→4pt→0 | 是（连点只留最后一次） |

### 4.2 T1 旋转轴（必须照此画，画错就变「卡片飞走」）

旋转轴 = **卡片左侧书脊线**（`transform-origin: left center`，原点落在书脊中线偏内 2pt），不是卡片中心。封面绕此轴 rotateY 0→-6°→0，同时整体位移由卡片 rect 插值到全屏 rect；正文层不参与 3D，仅 opacity 交叉。z 序严格按上表，玻璃按钮最后 260ms 淡入——全页仅此 1 处玻璃。

### 4.3 动效关闭态对照稿（回归基准，T1/T2/T4）

| ID | 关闭态行为 | 回归检查点 |
|---|---|---|
| T1 | 直切阅读页（0ms），无缩放/位移/3D；返回按钮与正文**同帧出现**（不保留 260ms 延迟） | 关闭前后正文首行 y 坐标 diff = 0；无残影层 |
| T2 | 源名直换（无 blur、无位移），源色直接改值（无扫层） | 卡片尺寸前后 diff = 0；竖排文字断行位置不变 |
| T4 | 直切回书架（0ms），阅读页 opacity 1→0 0ms，书架不播阴影过渡 | 落位卡片 rect 与关闭前一致；无 1.02 过冲残留 |

通用：全局总关 = 所有时长 0 + 直接置终态；系统「减弱动态效果」优先于本地设置；关闭后首屏与翻页性能不得低于开启态（NFR-07）。
